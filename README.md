# 🐱 FindCat — ระบบค้นหาแมวด้วยการวิเคราะห์ใบหน้าโดยใช้ AI

FindCat เป็นโปรเจกต์ต้นแบบที่พัฒนาขึ้นสำหรับการแข่งขัน SUT Hackathon โดยมีแนวคิดในการนำเทคโนโลยีปัญญาประดิษฐ์ (AI) และคอมพิวเตอร์วิทัศน์ (Computer Vision) มาใช้ในการตรวจจับและวิเคราะห์ลักษณะใบหน้าของแมว เพื่อค้นหาแมวที่มีลักษณะใบหน้าคล้ายคลึงกันจากฐานข้อมูล

ระบบประมวลผลภาพใบหน้าแมวเพื่อสกัดคุณลักษณะเฉพาะ (Feature Extraction) จากนั้นนำข้อมูลที่ได้ไปค้นหาความคล้ายคลึงด้วย FAISS เพื่อแสดงผลลัพธ์แมวที่มีลักษณะใกล้เคียงกัน

## ✨ ฟีเจอร์หลัก

- **ตรวจจับใบหน้าแมว (Cat Face Detection)** — ตรวจจับตำแหน่งใบหน้าและจุดสำคัญบนใบหน้าแมวจากรูปภาพ
- **สกัดคุณลักษณะจากภาพ (Feature Extraction)** — ใช้โมเดล ResNet18 ในการสร้างเวกเตอร์คุณลักษณะขนาด 128 มิติ
- **ค้นหาความคล้ายคลึง (Similarity Search)** — ใช้ FAISS ในการค้นหาใบหน้าแมวที่มีคุณลักษณะใกล้เคียงกัน
- **จัดการข้อมูลแมว (Cat Management)** — รองรับการจัดเก็บข้อมูลและรูปภาพของแมว
- **ระบบยืนยันตัวตน (Authentication)** — ใช้ JWT สำหรับการยืนยันตัวตนผู้ใช้งาน
- **โครงสร้างระบบ Marketplace** — มีโครงสร้างข้อมูลสำหรับผู้ใช้งาน แมว ศูนย์พักพิง วัคซีน คำสั่งซื้อ และการสนทนา

## 🔍 ขั้นตอนการทำงาน

1. **รับรูปภาพ** — ผู้ใช้งานเลือกรูปภาพแมวที่ต้องการค้นหา
2. **ตรวจจับใบหน้า** — ระบบใช้ YOLOv5-Face ตรวจจับใบหน้าแมวและตำแหน่งจุดสำคัญ
3. **ประมวลผลภาพ** — จัดเตรียมและปรับภาพใบหน้าให้อยู่ในรูปแบบที่เหมาะสม
4. **สกัดคุณลักษณะ** — ใช้ ResNet18 สร้างเวกเตอร์คุณลักษณะขนาด 128 มิติ
5. **ค้นหาความคล้ายคลึง** — ใช้ FAISS เปรียบเทียบเวกเตอร์กับข้อมูลในฐานข้อมูล
6. **แสดงผลลัพธ์** — แสดงรายการแมวที่มีคุณลักษณะใกล้เคียงกันสูงสุด 5 รายการ

## ⚠️ ข้อจำกัดของระบบ

FindCat เป็นโปรเจกต์ต้นแบบที่พัฒนาขึ้นเพื่อทดลองแนวทางการตรวจจับใบหน้าแมวและค้นหาความคล้ายคลึงของภาพ โดยยังมีข้อจำกัดดังนี้

- ผลลัพธ์เป็นการค้นหาภาพที่มีคุณลักษณะใกล้เคียงกัน ไม่ใช่การยืนยันตัวตนของแมวอย่างสมบูรณ์
- โมเดลสกัดคุณลักษณะยังไม่ได้ผ่านการฝึกและประเมินผลเฉพาะทางสำหรับการจดจำอัตลักษณ์แมว
- คุณภาพของผลลัพธ์อาจเปลี่ยนแปลงตามความคมชัด แสง มุมกล้อง และคุณภาพของภาพ
- จำเป็นต้องพัฒนาและทดสอบเพิ่มเติมก่อนนำไปใช้งานจริงในระดับ Production
